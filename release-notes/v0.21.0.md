这一版把 PDF 预览从浏览器自带的 iframe 升级为基于 mozilla pdf.js 的原生渲染查看器，左侧带可折叠目录、右侧是带工具栏的文档主区，阅读体验和交互完整度都上了一个台阶。

## PDF 预览

- 内嵌 PDF 预览改用 pdf.js（pdfjs-dist 5.4）逐页渲染为 canvas，按设备像素比绘制，高分屏下文字与线条依然清晰。
- 新增左侧目录侧栏：解析 PDF 大纲（书签），递归解析每个条目的目标页码，支持可折叠嵌套层级，点击即跳转到对应页并高亮当前项；无目录的 PDF 给出明确提示。
- 顶部工具栏支持显隐目录、缩小 / 放大、适应宽度、重置缩放、当前页码输入与总页数显示，并展示文件名。
- 适应宽度以首页宽度为基准自动计算缩放，侧边栏开关或窗口缩放后通过 ResizeObserver 自动重排。
- 缩放切换会取消上一轮渲染任务，避免同一 canvas 重叠渲染竞争。
- pdf.js worker 以独立资源加载，Vite 与 electron-vite 打包均正常输出。
