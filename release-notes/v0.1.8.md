## 小枢原生浏览器工作台

- 新增应用级浏览器运行时，以稳定 `tabId` 管理标签页身份、顺序、激活状态、页面连接与会话恢复。
- 为小枢加入原生浏览器工具，可管理标签页、导航、读取页面、点击输入、滚动、发送按键、执行 JavaScript、等待页面状态及截取页面图像。
- 全局小枢输入框支持 `@` 引用一个或多个浏览器标签页，并在发送时检查标签页是否仍然打开。
- 浏览器标签页实时同步页面标题、URL、Favicon、加载失败、音频播放和 Agent 操作状态；普通新页面与认证弹窗分别路由。
- 地址栏加入本地历史与搜索建议、已打开标签页优先匹配，以及 Google、Bing、Baidu、DuckDuckGo 和自定义搜索模板。
- 新增本地站点 CSS 规则、阅读模式基础能力，以及供小枢调用的样式管理工具。
- 移除浏览器内独立的“小枢 · 网页助手”，网页工作统一进入全局小枢会话。
- 长期记忆升级为事实、偏好、项目记忆和推断画像分层存储，支持去重、冲突替换、启停、编辑、删除与重建。
- 下载进度改为应用内状态区域展示，并加强浏览器 WebContents 注册与工具调用的安全边界。
