这一版把 pi 生态真正接入了脉络：应用内可以直接安装、启用和管理 pi 扩展包与 Skills，输入区的 `/` 指令也升级为运行时加载的 Pi 指令，不再依赖内置写死的几条模板。

## Extensions & Skills 管理

- 设置新增「Extensions & Skills」独立页：Extensions、Skills、Packages、路径四类入口，支持搜索、来源徽标、启用开关、错误状态与诊断。
- 支持从 pi.dev / pi package 生态安装扩展包（npm、git、HTTP/SSH URL、本地 package），可启用、禁用、删除、更新，安装根目录为 `~/.mailuo/ai/packages/`。
- 支持 skills.sh 安装方式：应用内直接调用 `npx skills add <owner/repo>` 拉取 skill，写入受控目录，不污染终端 `~/.pi`。
- 可以登记并导入终端已经安装到其他目录的 `.pi` / `.agents` 资源路径，来源一目了然。
- 扩展与 skills 支持自定义路径、查看详情、打开所在目录；skill 可新建、编辑、按名称启用。
- 危险操作带权限提示；应用默认仍不读取或回退到 `~/.pi`、项目 `.pi`、`~/.agents`、Provider 环境变量或登录 shell 凭据。

## Pi 运行时指令

- 输入区 `/` 指令改为按当前项目与模型实时加载的 Pi 运行时能力：扩展、prompt 与 skill 统一成为候选，带来源徽标，选择后按对应模板注入。
- 会话按启用状态只装载对应资源，配置变化后自动重置常驻 assistant，后续对话立即生效。
- 旧的全局通知已移除，避免打扰；AI 配置的 Provider、模型库与上下文策略保持独立于 pi CLI。

## 其他

- 新增 ai-config、pi-resources、窗口生命周期等模块的单测，覆盖包管理、资源发现、skills.sh 安装与路径导入等关键路径。
- 旧版 AI 配置文件无需手工迁移，默认值与兼容逻辑自动补齐 pi 资源配置。
