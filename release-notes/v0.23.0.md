这一版带来了全新的「定时任务」：像 Codex 的 Scheduled Tasks 一样，为每个项目配置"时间 + 提示词"，小枢会按时自动执行并交付报告。另外修复了 PDF 预览滚动条抖动的问题。

## 定时任务（Scheduled Tasks）

- **项目维度的自动化**：为任意项目创建定时任务，设定提示词（例如"汇总本周进展写成周报"），小枢会在指定时间自动执行一轮完整对话，产出 Markdown 报告。
- **灵活的排期**：支持每天 / 每周（可多选星期几）+ 具体时刻，本地时区；面板里实时显示"X 小时后"倒计时。
- **独立后台执行**：定时任务在独立会话中运行，自动注入该项目的任务快照与长期记忆，只带文件读写工具，不依赖窗口——macOS 关闭窗口后依然按时运行；不占用你和小枢的对话，也不会互相打断。
- **运行历史**：每次运行（定时 / 手动）都有完整记录：状态、耗时、触发方式，点开即看 Markdown 结果；失败的运行会给出可读的错误原因。
- **完全可控**：支持立即运行、运行中随时停止、启用/停用开关、编辑与删除；应用没开而错过的触发会记为"已错过"，不会悄悄补跑。
- **专属模型路由**：AI 设置里新增「定时任务」用途，可以为它单独指定模型（比如用更便宜的模型跑日报），也可以在单个任务上直接覆盖。
- **完成提醒**：任务跑完会发系统通知；应用开着时面板实时刷新状态。

## 入口

- 左侧 Ribbon 新增「定时任务」按钮；
- 项目右键菜单新增「定时任务」，直接进入该项目的任务视图。

## 问题修复

- **PDF 预览滚动条抖动**：改为按总页数构建全页占位的虚拟滚动条——滚动总高度由页数决定，不再随页面渲染/回收变化；拖动滚动条可直接跳到文档任意位置，缩放时以当前页为锚点保持位置稳定。
