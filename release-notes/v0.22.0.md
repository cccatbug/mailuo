这一版彻底重写了 PDF 预览，支持文本选择复制、突破 50 MB 文件上限、并针对大文档做了窗口化渲染优化。

## PDF 预览重构

- **支持选中和复制文本**：每页在 canvas 上方叠加透明文本层（pdf.js TextLayer），鼠标可选中跨页文本并按 Ctrl+C 复制。
- **大文件流式加载**：PDF 不再 base64 整文件读入内存，改为本地 HTTP 流式服务（Range/206 分块），pdf.js 按需拉取所需页数据；57 MB / 4000 页文档 1.6 秒打开，跳页实时渲染，原有的 50 MB 硬上限已移除。
- **窗口化渲染**：只渲染视口附近页面（中心页 ±2/+5），远处页面自动回收 DOM 和显存；4000 页文档不再一次性全渲染，内存和性能均可控。
- **键盘导航**：PgUp / PgDn / Space / Home / End / 方向键翻页；页码输入改为按回车生效，不再逐个字符跳页。
- **智能滚动**：滚动到未渲染空白区时按平均页高估算目标页，渲染窗口自动跟随。
- **修复若干当前版本的 bug**：切换文件时旧页面残留、跳转到未渲染页无法定位、超大页在 HiDPI 下超 GPU 纹理上限、渲染失败重试循环等。
